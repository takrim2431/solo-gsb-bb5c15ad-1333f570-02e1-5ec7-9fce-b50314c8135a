# 扫描印刷稿套色偏移校准工具

基于 **Node.js + Express + 原生 Canvas 前端**（无前端框架、无构建步骤）的套色（registration）校准 Web 应用。
上传**参考图**与**扫描图**，在两图上成对拾取控制点，系统以**全部点做仿射最小二乘拟合**，实时显示每对控制点的残差、标出最大异常点，将扫描图经变换后与参考图叠加对比，并可导出六参数矩阵与残差 JSON。

> 所有图像处理均在浏览器本地完成，图片不会上传或落盘；服务端只负责托管静态页面。

## 功能一览

- 两图成对点击控制点，**至少 3 对**（建议 ≥4 对），编号一一对应
- 对**全部点**做 2D 仿射最小二乘拟合（旋转 / 缩放 / 错切 / 平移，共 6 参数）
- **实时残差表**：逐点显示残差（px）与坐标，最大残差点红色高亮并在图上画红圈
- **近共线拒绝**：参考点散布矩阵特征值比 λmin/λmax < 1×10⁻⁴ 时拒绝计算并提示重新布点
- 任一点的增删都会**立即重算**并重绘两幅控制点图与叠加图
- 控制点删除：残差表每行的 ✕ 按钮（成对删除），或切换到「✕ 删除点」模式后点击图上标记
- **叠加预览**：同一画布先绘参考图，再用拟合矩阵的逆变换扭曲扫描图叠加；提供不透明度滑杆
- **导出 JSON**：`affine-matrix.json`（六参数矩阵、3×3 矩阵、逆矩阵、RMS 等）与 `residuals.json`（逐点残差）

## 使用步骤

1. 分别上传**参考图**（基准版面）和**扫描图**（待校准的扫描件），支持 PNG / JPEG 等浏览器原生格式。
2. 默认处于「＋ 添加点」模式。在两幅图上按**相同顺序**点击对应特征（套准标记、十字线、角点等）：
   第 1 个参考点配第 1 个扫描点，第 2 个配第 2 个，依此类推。
   - 蓝色标记 = 参考图点，橙色标记 = 扫描图点，标记内数字为点对编号
   - 琥珀色「!」标记 = 该点尚无对侧对应点（未成对，不参与拟合）
3. 达到 3 对后自动拟合；每增删一个点都会立即重算。
4. 查看残差表与状态条：
   - 绿色：拟合成功，显示 RMS / 最大残差与异常点编号
   - 黄色：成功但控制点分布偏狭长（λmin/λmax < 10⁻³），建议补点
   - 红色：**近共线被拒绝**（< 10⁻⁴）或不足 3 对
5. 在「变换叠加预览」中拖动不透明度滑杆，观察两套图文的套色错位；
   删除可疑异常点后结果即时更新。
6. 点击「导出矩阵 JSON」「导出残差 JSON」保存校准结果。

## 数学说明

### 仿射模型

拟合方向：扫描图坐标 = M · 参考图坐标

```
[x']   [a c e] [x]
[y'] = [b d f] [y]
[1 ]   [0 0 1] [1]
```

对 n 对控制点建立 2n 个方程，用最小二乘求解六参数 `(a,b,c,d,e,f)`。
实现上先对参考点中心化，再解 3 阶正规方程（选主元高斯消元），数值稳定。

### 残差

第 i 对点的残差向量为 `rᵢ = scan_i − (A·ref_i + t)`，表中残差为其模长 `|rᵢ|`；

```
RMS = sqrt( Σ|rᵢ|² / n )
```

最大残差点被标记为最大异常点。注意恰好 3 对点时仿射可被唯一确定（残差恒为 0，无法评估点质量），
因此建议至少使用 4 对。

### 近共线判定

对参考点中心化后的 2×2 散布矩阵 `S = Σ(p−m)(p−m)ᵀ` 求特征值 λmin、λmax。
当 `λmin/λmax < 1e-4`（点几乎落在一条直线上）时，拟合方程病态、参数不可靠，系统直接拒绝计算。
阈值常量定义在 `public/affine.js` 的 `COLLINEAR_RATIO`。

### 叠加变换方向

底图是参考图（参考坐标系）。绘制扫描图时使用 M 的逆矩阵 M⁻¹，
通过 Canvas `setTransform` 风格的 `ctx.transform(a,b,c,d,e,f)` 将扫描像素扭曲回参考坐标系对齐。

## 常见问题

- **提示「近共线」？** 三个点几乎在一条直线上。请在垂直于该线的方向补点，使控制点呈三角形铺开。
- **残差全为 0？** 说明只用了 3 对点（仿射恰好穿过三点）。增加第 4 对及以上点才能暴露扫描/点选误差。
- **点错了怎么办？** 切到「✕ 删除点」模式点图上标记，或在残差表点该行 ✕（成对删除）；「清空全部控制点」可重来。
- **换图片后点没了？** 重新上传某一侧图片会清空该侧控制点（旧坐标对新图无意义），这是预期行为。
